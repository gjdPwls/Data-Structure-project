# 스팸 조회 시스템

## 프로젝트 개요
계좌번호, 전화번호, 이메일과 같은 다양한 입력 데이터의 스팸 여부를 빠르게 판별하기 위한 C++ 기반 터미널 프로그램이다.  

블룸 필터를 활용한 1차 고속 필터링과 CSV 기반 데이터베이스 조회를 결합하여 속도와 정확성을 동시에 확보하였다.  

또한 터미널 로그를 통해 데이터 입력부터 필터링, 탐색, 결과 출력까지의 전 과정을 단계별로 확인할 수 있도록 설계하였다.

# 시스템 구성

| 입력 처리: 입력값 정규화 및 다중 해시 생성 |
| 필터링: 블룸 필터 비트 배열 기반 1차 고속 판별 |
| 탐색 조회: CSV DB를 통한 실제 데이터 존재 여부 확인 |
| 결과 출력: 정상/스팸 판정 + 처리 시간 로그 출력 |
| DB 관리: 신규 데이터 등록 및 블룸 필터 동기화 |
